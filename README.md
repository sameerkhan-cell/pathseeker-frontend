# 🌟 PathSeeker — Career Passport Platform (Frontend)

> **PathSeeker Frontend** is built with React 18, Vite, TailwindCSS, GSAP, and Lucide Icons. It features 22 fully responsive pages (15 user-facing public/protected pages + 7 admin management pages) with a dark/light design system, DM Serif Display typography, and 3D GSAP passport scroll sequence.

- **Frontend Repo**: [github.com/sameerkhan-cell/pathseeker-frontend](https://github.com/sameerkhan-cell/pathseeker-frontend)
- **Backend Repo**: [github.com/sameerkhan-cell/pathseeker-backend](https://github.com/sameerkhan-cell/pathseeker-backend)

---

## ⚡ Quick Setup Instructions

```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev
```

App runs at `http://localhost:5173`.

---

## 📋 System Assumptions & Scope

- **Public Access**: Landing Page (`/`), Career Bank (`/careers`), Aptitude Quiz (`/quiz`), Multimedia Center (`/media`), Success Stories (`/stories`), Resource Library (`/resources`), Login (`/login`), Register (`/register`).
- **Protected Access**: Dashboard (`/dashboard`), Profile (`/profile`), Bookmarks (`/bookmarks`), Feedback (`/feedback`), Story Submit (`/stories/submit`), Admin HQ (`/admin/*`).
